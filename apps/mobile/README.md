# Roster Loom — mobile app

Expo / React Native client sharing `@roster-loom/core` with the web app.

Run it from the repo root:

```bash
npm run mobile
```

Full setup — Expo Go, environment variables, the LAN-IP gotcha, and how
the app talks to the web backend — is in
**[docs/MOBILE.md](../../docs/MOBILE.md)**.
